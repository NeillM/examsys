# Form

This collection allows the building of WAI compliant forms.

You can either build and render the entire form in one go:

```php
$renderer = new \render($config);

$form = new Form(
    action: 'submit.php',
    method: Form::METHOD_POST,
);

$form->->addElement(new Text(
    id: 'username',
    name: 'username',
    label: $string['username'],
    autocomplete: 'username'
));

$form->->addElement(new Password(
    id: 'password',
    name: 'password',
    label: $string['password'],
    currentpassword: true,
));

$form->setStandardButtons($string['submit'], $string['cancel']);

$renderer->renderComponent($form);
```

or alternatively for more complex use cases build the form like:

```php
$renderer = new \render($config);

$form = new Form(
    action: 'submit.php',
    method: Form::METHOD_POST,
);
$form->setStandardButtons($string['submit'], $string['cancel']);

$renderer->renderComponent($form, '@form/form_start.html');

$username = new Text(
    id: 'username',
    name: 'username',
    label: $string['username'],
    autocomplete: 'username'
);
$renderer->renderComponent($username);

$passwword = new Password(
    id: 'password',
    name: 'password',
    label: $string['password'],
    currentpassword: true,
);
$renderer->renderComponent($passwword);

$renderer->renderComponent($form, '@form/form_end.html');
```

when rendering parts of the form separately if you are intending to use the file component you
will need to specify the data encoding when creating the form:

```php
$form = new Form(
    action: 'submit.php',
    method: Form::METHOD_POST,
    encode: Form::ENCODE_DATA,
);
```

if a File component is passed to the `addComponent()` method of a form the encoding is automatically set.

## Fields available

### Simple fields

* Hidden
* Select
* TextArea

#### Buttons

* Button
* Reset
* Submit

#### Inputs

* Checkbox
* Color
* Date
* Email
* File
* Number
* Radio
* Range
* Search
* Telephone
* Text
* Time
* Url

### Complex fields

#### CheckboxGroup

This is designed to adding a set of checkboxes that should be treated as a single field

The values selected will be submitted as an array

#### GeneralGroup

This is designed to hold a set of related fields, screen readers will be able to describe the
relationship that exists between the field.

#### RadioGroup

This is designed to hold a set of radio buttons that are options of one field

#### StaticComponent

This element can be used to output html into a form that is generated by a component.

#### StaticHtml

This element can be used to output any arbitrary html that is entered as its value, you should normally use
one of the other static components in preference to this.

#### StaticTemplate

This element can be used output the html from any template in ExamSys into the form.
